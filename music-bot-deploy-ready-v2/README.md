# DJ NINO — Deploy-Ready Music Bot 🎧

## 🔧 Features
- Discord Bot with YouTube + Spotify playback
- Spotify OAuth (multi-user)
- MongoDB for playlist / ranking
- Web UI (React) with EN/TH support
- Request songs via Web
- Public playlist sharing
- SSL-ready for domain: dj-nino.live

## 🚀 Deploy Steps
1. Configure `.env` with your secrets
2. Deploy `/frontend` to Vercel
3. Deploy `/backend` to Render / Railway
4. Set up your domain `dj-nino.live` to point to the backend
5. Ensure SSL certs via Vercel / Let’s Encrypt
